🌍 2-Body Orbital Simulation (Earth–Sun)

This project simulates the gravitational interaction between Earth and Sun using numerical methods (Verlet Integration).

🚀 Features
Realistic orbital motion based on Newtonian gravity
Barycenter (center of mass) reference frame
Energy conservation visualization (KE, PE, Total Energy)
Animated orbit with trailing path
NASA-style dark visualization
🧠 Physics Concepts
Newton’s Law of Gravitation
Two-body problem
Numerical integration (Verlet method)
Energy conservation
🛠️ Tech Stack
Python
NumPy
Matplotlib
▶️ How to Run
pip install -r requirements.txt
python main.py
📊 Output
Animated orbit of Earth around Sun
Real-time speed and position tracking
Energy conservation graph
